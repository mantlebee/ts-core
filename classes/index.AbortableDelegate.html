    Class AbortableDelegate<TArgs, TResult>

    Runs an async function so that the latest call wins.

    Each call aborts the running call, if any: its AbortSignal is aborted with an AbortedException as reason and its promise rejects with the same exception immediately, without waiting for its function to end. When the function of a superseded call settles later, its result is discarded and its rejection is swallowed, so a function that cannot cancel its work (a request without signal support) is still safe to wrap.

    A cooperative function checks signal.aborted after each await and skips its side effects, or passes the signal to fetch and the like.

    A call made from inside the function supersedes the outer call, as any other call would; so does a call made from an "abort" listener of the superseded signal, which supersedes the call that aborted it before that call runs. The class does not debounce: the function is invoked synchronously by call; compose it with DebouncedDelegate when a quiet time is wanted.

    Example

    // Cooperative: the signal is passed to fetch, the result applied only when
    // the call is still the latest one.
    const search = new AbortableDelegate(async (signal, query: string) => {
      const response = await fetch(`/api/users?q=${query}`, { signal });
      const users: User[] = await response.json();
      if (!signal.aborted) render(users);
      return users;
    });
    search.call("a").catch(() => undefined); // superseded: rejects with AbortedException
    const users = await search.call("ab"); // the result of "ab"

    Example

    // Plain check: the reader cannot be cancelled, the side effect is skipped.
    const load = new AbortableDelegate(async (signal, id: number) => {
      const item = await repository.get(id);
      if (signal.aborted) return item;
      selected = item;
      return item;
    });
